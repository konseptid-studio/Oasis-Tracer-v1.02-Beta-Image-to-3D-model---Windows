# 🏜️ Oasis Tracer v1.02 Beta

**Image to 3D Print & Vectorization Tool for Multicolor 3D Printing**

Oasis Tracer is a Windows x64 image-to-STL / SVG / 3MF generator designed for multicolor 3D printing, segmented artwork, lightboxes, decals and relief workflows. The program focuses on stable printable geometry, clean slicing behavior and physically separated color regions optimized for real manufacturing workflows.

---

## ✨ Key Features

- Converts images into ready-to-print multicolor 3D models 
- Exports **STL, SVG, and 3MF** formats
- Optimized for **multicolor 3D printing** (Bambu Lab, Prusa, etc.)
- Clean, physically separated color regions
- No AI • Fully offline • One-time purchase
- Commercial use of generated models allowed
- WeightStackK Layered Quantizer
